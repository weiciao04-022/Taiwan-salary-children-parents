# Taiwan-salary-children-parents

台灣薪水最高的年輕人，來自哪一種家庭？資料新聞練習作品。

手法參考《紐約時報》Upshot 2018 年〈Extensive Data Shows Punishing Reach of Racism for Black Boys〉的流動點陣圖。原作從父母往下追蹤孩子；這份資料的分母是子女，所以本作品把方向反過來，從子女往回追溯父母。

## 資料
- 王宜甲、林心怡〈臺灣跨世代薪資移轉與傳遞〉表 8（5×5 薪資移轉矩陣）
- 原始調查：中研院華人家庭動態資料庫（PSFD）2004–2016（缺 2013）
- 列為子女月均薪五分位、欄為父母月均薪五分位，每列加總 100%

- `data/raw/`：原始轉移矩陣
- `notes/sources.md`：來源、表格方向、待查證清單
