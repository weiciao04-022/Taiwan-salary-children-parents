# 同一個起點，兒子和女兒的路一路分岔

台灣男性與女性，從出生、工作、繼承、土地到退休的差距。資料新聞練習作品。

敘事方式參考《紐約時報》Upshot 2018 年〈Extensive Data Shows Punishing Reach of Racism for Black Boys〉。

## 檔案
- `index.html`：互動頁面（單一檔案，可直接用 GitHub Pages 發布）
- `data/raw/`：原始資料（來源見 notes）
- `data/processed/`：計算結果
- `notes/sources.md`：來源、計算方式、待查證清單
- `archive/`：舊版本
