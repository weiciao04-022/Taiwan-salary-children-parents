## 表格方向（重要）
- 列 = 子女薪資五分位；欄 = 父母薪資五分位；**每列加總 100%**
- 所以每格的意思是「某薪資組的子女中，有多少 % 的父母落在某組」
- 不能讀成「某組父母的子女中，有多少 % 落在某組」（NYT 原作的問法）
- 驗算：各欄加總 97.69 / 103.78 / 118.14 / 89.48 / 90.91，不等於 100
  - 推測：配對樣本中，各父母組的人數不一樣多。約 53% 的父母對應一名以上子女，論文全部保留。此為推測，待向作者確認。
